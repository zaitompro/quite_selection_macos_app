QuietSelection 1.7.0

Перенесён выбранный дизайн: вкладки занимают всю ширину боковой панели, без боковых отступов у подсветки. Выбранный раздел, включённые переключатели и заполненная часть ползунка используют приглушённый синий #1B4B7E из согласованного макета. Общие настройки цветов и доступности macOS не меняются.

Разделы настроек оформлены вертикальной панелью вкладок с выделением текущего раздела. «Общие» расположены первыми и открываются при каждом вызове настроек. Между разделами можно переходить мышью или стрелками, когда панель разделов в фокусе.

Кнопка «Читать» в строке меню открывает короткое меню: версия, «Настройки…», «Завершить QuietSelection». Command + Q и Command + W закрывают только настройки. Завершение приложения доступно явно через меню или кнопку «Завершить» в окне.

Если приложение не возвращает элемент с фокусом, QuietSelection дополнительно запрашивает текущий элемент у macOS. Для ChatGPT/Codex (com.openai.codex), если оба запроса не дали результата, теперь читается стандартный атрибут AXRole приложения, затем через 150 мс фокус запрашивается повторно один раз. Общий предел ожидания остаётся 2 секунды. В Chromium запрос роли приложения включает поддержку Accessibility; применимость к установленной сборке ChatGPT требует ручной проверки.

Запрос роли не меняет системные настройки и не использует скрытые флаги доступности. Найденный при повторе элемент проверяется на принадлежность исходному приложению до чтения текста. Обход содержимого окна не выполняется. Не помогавшая проверка атрибутов окна из 1.5.4 удалена. Обычный успешный путь и путь Safari/Mail не изменены.

Если фокус не найден, сообщение содержит результаты запросов «прил.», «сист.» и «роль прил.». OK означает успешный результат; −25212 — значение отсутствует; −25205 — атрибут не поддерживается. Текст, заголовки окон и содержимое чатов в диагностику не попадают; отчёт не сохраняется на диск.

Основание для запроса роли: Chromium, BrowserCrApplication.accessibilityRole. Это свидетельство поведения Chromium, а не доказательство причины сбоя ChatGPT.

После выбора области экрана или отмены QuietSelection возвращает фокус предыдущему приложению. Если во время выбора вы сами переключились в другое приложение, выделение отменяется без переключения обратно.

Окно настроек поднимается на передний план при выборе «Настройки…» в меню. После закрытия настроек сочетания чтения продолжают работать. Command + Q и Command + W действуют на настройки, когда QuietSelection — активное приложение; в других приложениях их поведение не меняется.

Добавлено чтение области экрана: Control + Esc, выделение прямоугольника мышью, локальное распознавание и озвучивание привычными голосами.

Версия 1.4.2 учитывает представление списков в Firefox: текст выделенного веб-диапазона может включать маркеры списка, не входящие в сообщённую длину диапазона. Оба размера по-прежнему проверяются на предел 60 000. Читается только диапазон выделения. В тестовую страницу добавлены обычные, вложенные и нумерованные списки.

Версия 1.4.1 добавляет чтение выделенных подписей в собственном окне настроек и поддержку выделенных текстовых маркеров на разных типах веб-элементов, включая случаи пустого локального выделения при непустом выделении документа. Положение мыши не используется. Проверка Firefox и Codex на конкретных страницах требуется после обновления; универсальная совместимость не гарантируется.

Выделите текст и нажмите выбранное сочетание. Повторное нажатие останавливает чтение. Нажмите «Читать» в строке меню Mac, чтобы открыть настройки. Закрытие окна не завершает приложение.

Речь

Сначала настройте основной язык, его голос и скорость. Он используется при выключенном автоопределении и при неуверенном распознавании языка. Основной язык всегда участвует в автоопределении. Названия языков указаны на русском, по алфавиту; в списке голосов доступны только установленные системные голоса.

У каждого языка своя скорость по шкале от 0 до 100 (не проценты и не точный множитель). Изменения сохраняются автоматически и применяются со следующего чтения. «Прослушать» использует голос и скорость соответствующей карточки, независимо от автоопределения. Для русского, английского, японского, немецкого, французского, испанского и китайского есть свои тестовые фразы; для остальных используется русский пример.

Автоопределение языка

Включается тумблером «Автоопределение языка». Дополнительные языки добавляются кнопкой «Добавить язык», удаляются корзиной. Тумблер справа от корзины временно исключает язык из распознавания, сохраняя настройки. После удаления и повторного добавления голос и скорость также восстанавливаются. При смене основного языка прежний перемещается в дополнительные. Список имеет фиксированную высоту и прокручивается внутри; добавление языков не увеличивает окно.

Язык определяется локально для каждого предложения только среди основного и включённых дополнительных языков. При отсутствии результата, вероятности менее 0,65 или отрыве от второго кандидата менее 0,15 используется основной язык с его голосом и скоростью. Пороги не гарантируют правильности; для неоднозначного текста доступен ручной режим. Исчезнувший сохранённый голос не заменяется автоматически: карточка предлагает выбрать другой.

При переходе с предыдущей версии сохраняются выбор голосов, основной язык, режим и список автоопределения. Прежняя общая скорость становится начальной скоростью каждого языка. Настройки дополнительных языков можно редактировать и при выключенном автоопределении.

Сочетания клавиш

«Читать / остановить выделение». Варианты: Option + Esc и Option + Shift + Esc. Для Option + Esc штатное «Проговаривание выбранного текста» должно быть отключено или использовать другое сочетание. QuietSelection не меняет его настройку. При невозможности зарегистрировать новое сочетание прежнее сохраняется.

Для функции «Распознать и прочитать область экрана» доступны Control + Esc (по умолчанию) и Control + Shift + Esc. Левый Shift подходит. Повторное сочетание или обычное Option + Esc останавливает распознавание и речь; Esc отменяет выбор области.

Чтение с экрана

  1. Откройте тестовую картинку. Она содержит только заранее заданные фразы на русском, английском и японском.
  2. Нажмите Control + Esc. При первом использовании приложение объяснит необходимость разрешения macOS «Запись экрана». Выдайте его самостоятельно только QuietSelection. Если macOS предложит перезапуск приложения, согласитесь, затем снова нажмите сочетание.
  3. Обведите нужную строку мышью и отпустите кнопку. Рамка исчезнет, начнётся распознавание и чтение. До отпускания мыши Esc отменяет действие без получения изображения.
  4. Проверьте остановку через Option + Esc, пустую область без текста и повторное чтение. При наличии нескольких мониторов попробуйте каждый отдельно; область выбирается внутри одного монитора.

Используются язык, голос и скорость из раздела «Речь». В автоматическом режиме распознавание ограничено разрешёнными языками. В ручном режиме используется выбранный язык. Для проверки трёх языков на картинке включите автоматический режим с русским, английским и японским или проверяйте строки по отдельности, меняя язык.

Изображение выбранной области и распознанный текст обрабатываются в памяти на Mac, без файлов, сети или буфера обмена. Это разовый захват выбранного прямоугольника, не запись видео. Обычное чтение выделения не требует разрешения на экран. Результат зависит от качества изображения: лучше выделять один столбец разборчивого текста. Vision выбирает вычислительное устройство самостоятельно; использование исключительно Neural Engine не гарантируется.

Общие

Автозапуск включается тумблером. Если требуется одобрение macOS, появится пояснение и кнопка настроек входа. Окно настроек не открывается при обычном запуске. Приложение находится на SSD2TB: диск должен быть доступен при входе в учётную запись.

Здесь также показаны состояние разрешения «Универсальный доступ» и версия приложения. Разрешение нужно только для получения выделения по вашему сочетанию. При первом запуске включите доступ только для QuietSelection самостоятельно. Кнопка «Завершить» останавливает речь и закрывает приложение, но не отключает автозапуск.

Проверка после обновления

  1. Откройте «Читать», выберите голоса для русского, английского и японского, прослушайте их и настройте скорость.
  2. Настройте разные скорости языков и убедитесь, что они сохраняются после перезапуска. Включите автоматический режим, если хотите использовать его.
  3. Самостоятельно откройте тестовую страницу в Safari и тестовое письмо в Mail. Проверьте чтение, остановку повторным сочетанием и прокрутку стрелками сразу после чтения без смены фокуса. Настоящие письма для проверки не требуются.
  4. Закройте окно настроек и повторите чтение. При новом запуске приложения настройки должны сохраняться.

Данные и ограничения

Буфер обмена не читается и не изменяется. Нет эмуляции клавиш, отправки текста в сеть, журнала выделенного текста или запуска штатного контроллера проговаривания. Используются установленные голоса Apple через AVSpeechSynthesizer; сторонние голоса и Personal Voice исключены. Текст находится в памяти только для получения и синтеза.

Получение выделения использует только фокусный элемент, его роль/подроль и атрибуты выделения. Выбранный диапазон текстовых маркеров проверяется по поддержке атрибута, а не только по роли AXWebArea. Длина проверяется до чтения диапазона, предел — 60 000 единиц UTF-16. Полная страница, родители и дочерние элементы не обходятся. Защищённые поля и Secure Input блокируются. Неподдерживаемое выделение вызывает техническое сообщение с ролью и этапом запроса, без текста. В собственном окне используется выделенный диапазон текущего текстового редактора AppKit. Положение курсора не влияет на чтение.

Настройки увеличения, мыши, Safari, Mail и полного клавиатурного доступа не изменяются. Системные службы не перезапускаются. Способ получения выделения уже проверен пользователем в Safari и Mail; после обновлений macOS проверку прокрутки стоит повторить. Старые диагностические режимы из интерфейса удалены.

Обновления и технические проверки

Обновления подписываются постоянным локальным сертификатом и устанавливаются по прежнему пути. Не удаляйте ключ QuietSelection из «Связки ключей» и не создавайте новый для каждой сборки. Сохранение доступа при обновлении 1.3 → 1.3.1 подтверждено пользователем. Изменение политики macOS или отзыв разрешения пользователем всё же могут потребовать повторного разрешения.

Сборка: make build. Проверки выделения, голосов, языка и ограничений приватности, сборка тестов OCR: make test. У исполняемого файла доступны --speech-smoke и --rate-smoke для синтетического звука в памяти, --login-status для состояния автозапуска. --render-settings ПАПКА сохраняет изображения только собственного окна с тестовым состоянием, без чтения экрана или других приложений. --show-settings открывает окно при явном запуске.

build/OCRTests проверяет распознавание синтетических изображений, отмену, пустую область и координаты. build/OCRTests --hotkeys проверяет регистрацию двух сочетаний и сразу освобождает их; запускать до обновления, пока они не заняты приложением. Эти тесты не получают изображение экрана и не запрашивают разрешения.
